今日、運営している会社の X アカウント [@StableBuildInc](https://x.com/StableBuildInc) が凍結されました。ちなみに、無料アカウントで、X には課金していません。メールには、「inauthentic behaviors」（不正な行動）に関するルールに違反したため、とだけ書かれていて、何をしたとされているのかはわかりませんでした。

{% include figure.html
    url='/images/x/suspended.png'
    caption='X から届いた凍結の通知'
%}

ただ、メールの最後には笑ってしまいました。凍結されても X Premium のサブスクリプションは自動では解約されないそうです。つまり課金しているユーザーは、使えないアカウントのためにお金を払い続けることになります。課金していなくてよかったと思いました（笑）

{% include figure.html
    url='/images/x/premium.png'
    caption='凍結されても、課金は続く'
%}

サポートへの連絡が /dev/null に行くという最悪の事態も覚悟しつつ、公開フォームから異議申し立てをしたところ、1時間もしないうちに X サポートから返信があり、違反はなかったとしてアカウントが完全に復旧されました。

{% include figure.html
    url='/images/x/restored.png'
    caption='異議申し立てを受けてアカウントを復旧した X サポートからのメール'
%}

[LINE](/2025/08/14/soft-banned-from-line-ja.html)では、アカウントが停止されてから1年半ほど経ち、何を検知したのかを知るだけでも、訴訟を起こして1年以上かかりました。X のサポートのほうが LINE よりずっと親切で、驚きました。
